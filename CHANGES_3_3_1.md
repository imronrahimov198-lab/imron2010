# Stone Relief Studio Pro 3.3.1

Продолжение текущего кода 3.3; существующие инструменты не удалены. Полная программа собирается из `source/` в один `stone_relief_studio_fixed.py`.

## Подтверждённые причины и исправления

1. **Высота F12.** `build_shape()` в режиме free рассчитывал высоту по расстоянию до границы и углу. Все режимы затем дополнительно умножались на scale. Воспроизведение: angular, угол 80°, заданные 7 мм, multiplier 5 давали 35 мм в scale/limit/const. В 3.3.1 множитель применяется только в явно обозначенном режиме free. Новый exact нормирует покрытые отсчёты до введённых мм; округлая форма меняется с углом без изменения максимума. Добавлены проверки положительных/отрицательных углов, форм round/angular/plateau и Add/Replace. Отрицательные формы сохраняют прежнее ограничение минимального Z=0,05 мм.
2. **Размеры.** `update_lock()` блокировал X/Y/шаг при содержимом. Новые `model_dimensions_dialog()` и `apply_model_dimensions()` доступны по крупной верхней кнопке и меню «Модель». Новый проект сначала запрашивает размеры; отмена сохраняет текущий проект. Содержимое масштабируется по X/Y, сетка интерполируется линейно с прежним пределом 8 млн ячеек. Высоты сохраняются; изменение основания добавляет смещение Z. Масштабируются векторы/Безье, 2D-точки и координаты IRM. Для исходной сетки изменяются XYZ-координаты без изменения индексов граней и без карты высот. История теперь хранит также параметр высоты рельефа. Разрежение сетки может уменьшить детали; есть подтверждение.
3. **Направляющие.** `VectorView.mousePressEvent()` обрабатывает назначение одним щелчком по геометрии открытого вектора. `sw_begin_pick()` включает выделение, очищая режим рисования; `sw_complete_pick()` возвращает окно автоматически; `sw_pick()` не затирает вторую направляющую при повторном выборе того же вектора. Первая/вторая/сечения/Z имеют собственные цвета. Esc обрабатывается также общим shortcut, ранее перехватывавшим событие до VectorView. Промах и закрытый контур не меняют назначения. Проверены реальные QTest-клики по прямой и кубической кривой.
4. **F12: операция.** «Добавить» — переключатель режима, «Применить» выполняет его. Выбранная кнопка зелёная, операция написана над группой. Добавлена Replace; сохранены Add/Subtract/Highest/Lowest/Zero Inside/Zero Outside. `shape_apply()` показывает реальные Z max до/после, диапазон создаваемой формы и максимальное изменение в мм. Сложение выше `sp_depth` требует подтверждения; предпросмотр показывает предупреждение без модального окна. Отмена не меняет поверхность и историю. Ожидающий таймер предпросмотра останавливается при применении, отмене и закрытии.
5. **Завершение GUI.** При отладке нового hit-test через `QGraphicsView.items(point)` выявлен сбой Shiboken при завершении сценария промаха/отмены (проверки проходили, процесс завершался SIGSEGV). GDB показал освобождение типа `QGraphicsRectItem`. В итоговой реализации hit-test работает только с существующими VectorItem и их stroke-геометрией, не получает временные Qt-обёртки фона/фото. Сценарий повторно проверяется вместе с нормальным завершением процесса.

## Числа для проверки

- Плита 5 мм, начальная высота F12=0, exact=2, Add → Z max=7 мм.
- Отдельная плита 5 мм, exact=7, Add или Replace → Z max=12 мм.
- Последовательные Add 2 и Add 7 на одной плите → Z max=14 мм.
- Replace 7 после этой последовательности → Z max=12 мм.
- У округлой формы угол меняет кривизну нормированного профиля. Для угловых форм крутые линейные склоны обрезаются на заданной высоте: меняется переход к плоской вершине. Если для указанной ширины угол слишком мал, профиль нормируется до заданных мм — точная высота имеет приоритет над буквальным углом грани.
- В 3D GetScale()=(1,1,1); реальная верхняя граница актора и экспортированного STL соответствуют рассчитанному Z. X/Y не меняются при F12.

## Совместимость и границы

Формат проекта 5; чтение 2/3/4/5 сохранено. Новые поля exact/операция replace F12 поддерживаются валидатором и восстанавливаются при открытии, Undo/Redo и из настроек. Старые проекты открываются без изменения исходного файла; уже сохранённые высоты не пересчитываются. Прежняя 3.3 не понимает новые значения настроек exact/replace — используйте 3.3.1.

Независимые слои, Control Curves и полный STL Inspector остаются будущими этапами большого ТЗ. Здесь исправляются четыре срочных пункта. 3D-просмотр не усиливает Z; режима отдельного визуального усиления в этой версии нет. Линейная интерполяция при смене шага не восстанавливает отсутствующие детали. Тяжёлое изменение разрешения выполняется синхронно; фоновый перерасчёт этого диалога ещё не добавлен.
